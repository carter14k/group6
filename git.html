1.What is Git?

Git is a version control system. It keeps a history of every change you make to your files, so you can go back to an older version at any time.
Note: Git and GitHub are not the same thing. Git is the tool;GitHub is a website that stores Git projects online.

2.Installation

  1. Download Git from git-scm.com.
  2. Run the installer and accept the default options.
  3. Open your terminal and type:
    4. git --version
  4. You should see output like:
    5. git version 2.45.1
  5. Set your name and email:
    6. git config --global user.name "Your Name"
    git config --global user.email "you@example.com"

3.Common Commands

Everyday Git commands
Command What it does Example
git init Creates a new repository git init
git add Stages a file for commit git add index.html
git commit Saves a snapshot with a message git commit -m "message"
git status Shows changed files git status
git log Shows commit history git log --online
git push Uploads commits to GitHub git push origin main

Key terms

repository(repo)
A folder that Git is tracking
commit
A saved snapshot of your project
branch
A separate line of work, e.g main or feature-login

4.Keyboard shortcuts(VS Code)

  • Open terminal: ctrl +
  • Save file: Ctrl + S
  • Open command palette: Ctrl + Shift + P
  • Stop a running command: Ctrl + C

Common Error Messages

If you see fatal: not a git repository, it means you forgot to run git init.

If you see nothing to commit, working tree clean, you have no new changes. ✅
